# CodeAlpha Basic Chatbot

## 📌 Project Overview

This project is a simple rule-based chatbot developed using Python as part of the CodeAlpha Internship – Task 4.

The chatbot interacts with the user through the terminal and provides predefined responses to common messages.

## ✨ Features

- Greets the user with "hello"
- Responds to "how are you"
- Responds to "bye"
- Allows continuous conversation using a loop
- Handles unknown messages with a default response
- Simple and beginner-friendly Python implementation

## 🛠️ Technologies Used

- Python
- if-elif-else statements
- Functions
- while loop
- User input and output

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python chatbot.py
